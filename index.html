NextCity

Controlled Vocabulary Registry

Shared vocabularies for describing NextCity datasets, models and pipelines in the SADL GeoNetwork catalogue. Each term has a stable web address, which metadata records use to link their keywords back to this registry. The SKOS files for import into GeoNetwork are in the rdf folder.

Tool vocabularies

For software, models, pipelines and the digital twin. One vocabulary per field of the NextCity tool metadata template.

Fixed list

Type of Resource

Top-level classification of a tool record. Exactly one value per record: it tells users whether a resource is an interactive application or an algorithm, and if an algorithm, whether it is machine-learning based.

3 terms
Extensible

Other Category

Domain and functional categorisation of a tool beyond the ISO 19119 service types. Multiple values allowed; use these to say what field a tool serves and what it does.

17 terms
Extensible

Availability

Access status of a tool. Exactly one value per record; tells users whether and how they can obtain or run the tool.

5 terms
Extensible

Programming Language

Programming languages a tool is implemented in. Multiple values allowed; list the primary language first.

9 terms
Extensible

Platform

Where a tool is hosted or executed. Multiple values allowed; tells users what environment is needed to run it.

12 terms
Extensible

Framework / Library

Software frameworks and libraries a tool depends on. Multiple values allowed; documents what is needed to run or reproduce the tool.

25 terms
Extensible

Approach

The methodological paradigm or learning modality behind a tool. Mandatory for ML/DL algorithms; recommended for all algorithms so users know what kind of reasoning produces the outputs.

10 terms
Extensible

Architecture

The structural blueprint of a tool: how its components are organised and connected. Mandatory for ML/DL algorithms; one architecture may have several algorithm implementations.

16 terms
Extensible

Algorithm

The specific algorithms a tool implements. Multiple values allowed; use custom-method when no standard name applies and describe it in the record.

21 terms
Extensible

Processor

The type of processor a tool needs. Select the highest-power processor used. Mandatory for ML/DL algorithms.

4 terms

Dataset vocabulary

One shared vocabulary for all NextCity datasets.

Extensible

NextCity Dataset Keywords

A single shared vocabulary for tagging NextCity datasets. It covers the use case, place, theme, indicators, spatial unit, source data, production method and role of a dataset, so any dataset can be found by what it contains, where it comes from and how it was made. Pick every term that applies.
