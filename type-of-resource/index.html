Type of Resource

Fixed list

Top-level classification of a tool record. Exactly one value per record: it tells users whether a resource is an interactive application or an algorithm, and if an algorithm, whether it is machine-learning based.

Vocabulary URI: https://sadl-kuleuven.github.io/nextcity-registry/type-of-resource/ · SKOS file

tool

Interactive software with a user-facing interface, such as the NextCity digital twin, dashboards or web apps.

https://sadl-kuleuven.github.io/nextcity-registry/type-of-resource/#tool

ML/DL algorithm

Machine learning or deep learning model (supervised, unsupervised, reinforcement learning, etc.).

machine learning algorithm
https://sadl-kuleuven.github.io/nextcity-registry/type-of-resource/#ml-dl-algorithm

other algorithm

Computational algorithm not based on ML/DL, such as physically-structured models, emission factor chains, statistical and geostatistical methods, and data pipelines.

https://sadl-kuleuven.github.io/nextcity-registry/type-of-resource/#other-algorithm
