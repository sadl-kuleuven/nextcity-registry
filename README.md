# NextCity Controlled Vocabulary Registry

Controlled vocabularies used to tag NextCity datasets, models and pipelines in the SADL GeoNetwork catalogue.

Published at https://sadl-kuleuven.github.io/nextcity-registry/

- One page per vocabulary, e.g. `indicator/`; each term has an anchor, e.g. `indicator/#no2`. These addresses are the concept URIs used in metadata keywords.
- `rdf/` holds one SKOS file per vocabulary for import into GeoNetwork (Admin console > Classification systems > Thesauri, type `external`, category `theme`).

To change a term, edit both the RDF file and the matching HTML page, then re-import the RDF file into GeoNetwork.
